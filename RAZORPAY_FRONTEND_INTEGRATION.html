🔐 Razorpay Checkout Integration

How it works:
  1. Enter your booking ID (from apartment booking response)
  2. Click "Create Order" to get Razorpay order details
  3. Click "Open Checkout" to open Razorpay payment modal
  4. Complete payment in the modal
  5. System verifies and confirms payment
Response: 

        


        


        


        
📝 Integration Steps


        
Step 1: Login to get Token

        

POST /api/v1/auth/login
{
  "email": "user@example.com",
  "password": "password123"
}

Response includes: access_token (or tokens.access_token depending on endpoint)
        


        
Step 2: Create Booking (e.g., Apartment)

        

POST /api/v1/bookings/apartment
Headers: Authorization: Bearer {token}
{
  "apartment_id": "uuid",
  "check_in_date": "2026-06-15",
  "check_out_date": "2026-06-20",
  "guests": 2
}

Response includes: booking_id and total_price
        


        
Step 3: Create Razorpay Order

        

POST /api/v1/payments/razorpay/order
Headers: Authorization: Bearer {token}
{
  "booking_id": "uuid-from-booking"
}

Response:
{
  "payment_id": "uuid",
  "order_id": "order_SvZLidgPYGFjD9",
  "key_id": "rzp_test_SvYnusY18eShJP",
  "amount_paise": 3300,
  "currency": "USD",
  "user_name": "John",
  "user_email": "john@example.com"
}
        


        
Step 4: Open Razorpay Checkout Modal

        

// Include SDK
<script src="https://checkout.razorpay.com/v1/checkout.js"></script>

// Use response data
var options = {
  key: response.key_id,           // Razorpay Key ID
  amount: response.amount_paise,  // Amount in paise
  currency: response.currency,    // INR, USD, EUR, etc.
  order_id: response.order_id,    // Razorpay Order ID
  
  handler: function(response) {
    // After successful payment
    // response contains: razorpay_payment_id, razorpay_signature
    verifyPayment(response);
  }
};

var rzp = new Razorpay(options);
rzp.open();
        


        
Step 5: Verify Payment

        

POST /api/v1/payments/razorpay/verify
Headers: Authorization: Bearer {token}
{
  "payment_id": "uuid-from-create-order-response",
  "order_id": "order_SvZLidgPYGFjD9",
  "razorpay_payment_id": "pay_xxx",
  "razorpay_signature": "signature_from_handler"
}

Response: Payment confirmed, booking marked as paid
