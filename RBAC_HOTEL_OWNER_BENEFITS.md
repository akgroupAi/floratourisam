## 🔐 Security Scenarios

### Scenario 1: Receptionist Curiosity 👀
```
Receptionist tries to see competitor's bookings
(By hacking/guessing hotel ID)

Result:
Backend: "NO! This hotel is not assigned to you"
Response: 403 Forbidden
Audit Log: "Unauthorized access attempt recorded"
Owner: Notified of suspicious activity
Competitor: SAFE - data not accessed
```

### Scenario 2: Staff Member Leaves 👋
```
Hotel owner contacts Flora Admin
"Bob is no longer working here, disable his account"

Result:
Flora Admin: Disables Bob's login
Bob tries to log in: "Invalid credentials"
Bob tries to use old session: "Access denied"
Audit Log: "Bob's account disabled at 14:32"
Hotel Data: Bob can't access anymore
```

### Scenario 3: Data Breach at Flora 💥
```
(Worst case scenario: System-wide hack)

Result:
Attacker gets database: See ALL user data
But accesses: See users' assigned hotels only
Example: 
  - Bob(receptionist) → Green Hotel ONLY
  - Jane(owner) → Grand Plaza ONLY
  - Attacker sees: Bob can't access Jane's hotel
  - Damage: Limited to one hotel's data
  - GDPR: Compliant - access was already restricted
```
